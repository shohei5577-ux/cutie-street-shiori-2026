雨・遅延プラン

6月の東京は天気と交通で崩れやすいので、削る順番を先に決めておきます。

Day1が押したら

  • ＆TOKYOを短縮または翌朝用購入だけにする
  • ホテル戻りを優先して充電と身支度
  • 16:30有明着を守る

Day2が押したら

  • CHAVATYを削る
  • 原宿はAge.3×Qだけに絞る
  • 14:15表参道出発を守る

Day3が押したら

  • ヨドバシは買う物だけ見る
  • フライング・スコッツマンを短縮
  • 13:30ホテル荷物回収を守る

移動ルート

東京駅の京葉線長距離乗換を避けられる場面は避けて、体力を温存。

羽田空港 -> ホテル

  1. 羽田空港
  2. 東京モノレール「天王洲アイル」
  3. りんかい線「新木場」
  4. JR京葉線「潮見」

目安50-60分。到着日はこのルートが楽。

ホテル -> 有明アリーナ

  1. 潮見 -> 新木場
  2. 新木場 -> 豊洲
  3. 豊洲 -> 新豊洲
  4. 新豊洲から徒歩

目安30-40分。ライブ日は混雑分として+15分。

ホテル -> 池袋

  1. 潮見 -> 新木場
  2. 新木場 -> 池袋
  3. C3出口方面へ

目安45-55分。みそきん池袋店と相性が良い。

池袋 -> 原宿/表参道

  1. 池袋 -> 原宿
  2. 竹下通り
  3. キャットストリート
  4. 表参道

Day2は寄り道しすぎない。14:15出発がリミット。

秋葉原 -> ホテル -> 羽田

  1. 秋葉原 -> 東京 -> 潮見
  2. ホテルで荷物回収
  3. 潮見 -> 新木場 -> 天王洲アイル
  4. 羽田空港

13:30荷物回収、15:20-15:40羽田着が目安。

終演後

  1. 新豊洲駅へ戻る
  2. 豊洲経由でホテルへ
  3. 混雑時は国際展示場方面も候補

規制退場と駅混雑を見て、急ぎすぎない。
